# Shell 工作台

FlashShell 的主业：多会话终端、分屏、广播、监控，全部在一个窗口里。

## 核心能力

- **多 Tab**：SSH 会话与本机 PTY 并行
- **分屏**：最多 4 窗格，适合对照日志 / 多机操作
- **广播**：一键把同一命令发到多个窗格
- **xterm.js**：搜索、粘底跟随、右键菜单、主题配色
- **连接历史 / 连接管理器**：快速回到最近机器
- **导入**：Xshell / FinalShell 会话一键入港

## 典型用法

1. 首页进入 **Shell 模式**
2. 从机器列表打开会话，或新建本机终端
3. 需要对照时开启分屏；需要同步操作时开广播
4. 底部展开 SFTP 面板传文件（见 [SFTP](/features/sftp)）
5. 需要联调内网服务时开 [SSH 隧道](/features/tunnel)

## 与任务模式的关系

任务在跑远程步骤时，你可以随时切到 Shell 登上同一台机器排查。视图切换不会踢掉会话。
