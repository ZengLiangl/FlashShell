# SSH 隧道

本地转发与动态 SOCKS，把远程网络能力接到本机开发与联调流程。

## 能力概览

- **本地端口转发**：把本机端口映射到远程可达的服务
- **动态 SOCKS**：浏览器 / 工具走 SOCKS 访问内网
- **代理贯通**：HTTP / SOCKS 代理可作用到 SSH、SFTP 与更新请求

## 典型场景

- 本机浏览器访问远端仅内网暴露的管理台
- IDE / 客户端经隧道连远程数据库端口
- 公司网络下经代理建立 SSH

## 安全提示

隧道等于把远程可达性延伸到本机，请只在可信网络与明确用途下开启，用完及时关闭。
